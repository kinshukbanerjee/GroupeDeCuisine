# Groupe De Cuisine

Open Source Restaurant Operating System

Build once. Serve everywhere.

------------------------------------------

## Vision

Groupe De Cuisine is an open-source platform for modern restaurants.

It enables restaurants to manage:

• Orders
• Menu
• Customers
• QR Payments
• Kitchen Operations
• Notifications
• Analytics

from a single platform.

------------------------------------------
